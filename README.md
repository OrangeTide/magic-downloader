# Magic Downloader

A tool for downloading and organizing your purchased collections.

## Features

 * ability to index your collection without downloading anything
 * ability to selectively sync parts of your collection (download if new)
 * generates album and book covers from webstore or metadata
 * multiple backends

## Future Support

 * DriveThruRPG
 * Bandcamp
 * itch.io
 * gumroad
 * Amazon Music Library
